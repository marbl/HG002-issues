# HG002-issues

Welcome to the HG002-issues repository, where we track the status of
issues in the latest version of the assembly of HG002.

## Note

Our current release of the T2T-HG002 assembly is T2T-HG002v1.2. You can read more about
the Q100 project's HG002 assemblies [here](https://github.com/marbl/HG002).

Assembly issues recorded in this
repository are mainly user-submitted. If you believe there is an error in T2T-HG002v1.2
which is not annotated in the "v1.2 issues" track (group "Assembly Validation") of the
[HG002v1.2 browser](http://genome.ucsc.edu/cgi-bin/hgHubConnect?hgHub_do_redirect=on&hgHubConnect.remakeTrackHub=on&hgHub_do_firstDb=1&hubUrl=https://research.nhgri.nih.gov/CustomTracks/T2T_hubs/HG002_Q100/hub.txt), please take a moment to record it as a small (50 base pairs or less) or large
(spanning greater than 50 base pairs) issue in this repository. All newly-submitted
issues will be tagged with "v1.2" and "small_error" or "large_error" tags as appropriate.

Issues submitted to this repository for T2T-HG002v1.2 will be also be included in new versions of
the browser's v1.2 issue track to avoid redundancy in this repo.
